INTRUKSI JALANKAN ETL:
1. Install requirements: pip install -r requirements.txt
2. Jalankan main program: python main.py
3. Hasil akan muncul di products.csv, Google Sheets, dan Supabase.

INSTRUKSI TESTING:
1. Jalankan semua test: python -m unittest discover tests/
2. Cek coverage: pytest --cov=. tests/
